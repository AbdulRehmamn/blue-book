# Pacific coverage — setup required

This is a resumable collection tool, not a completed all-counties database.
Only the user's supplied Los Angeles / Santa Barbara / Ventura general-contractor search is preconfigured. Its uploaded page advertises 83 pages. No other region or trade IDs have been guessed.

For broader coverage, use Blue Book's normal search interface and copy the actual results URL for each required region and category into the app, then select the appropriate category and click Add searches. The app follows pagination links returned by those searches. Repeat for general contractors, each subcontractor trade, and owner/developer searches that Blue Book actually offers. A category label in this app does not change the website's search filter.

Coverage checklist:
- California: all counties; include every Blue Book regional directory covering the state.
- Washington: all counties.
- Oregon: Pacific-time areas; verify the Mountain-time portion of Malheur County separately.
- Nevada: Pacific-time areas; verify local time-zone exceptions separately.
- Idaho: Pacific-time northern counties only; do not treat the entire state as Pacific.

Blue Book regions do not equal counties. This release does not automatically enumerate or certify county coverage or determine local time zones. Review the site's region/county filters and add the relevant searches. Never describe a completed queue as exhaustive all-Pacific coverage without checking these searches.
